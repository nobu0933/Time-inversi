# 初回の角着手と時間反転の調査

`time_inversi.corner_study`は学習を行わず、100回学習済みPROのチェックポイント内にある局面から、未使用の角とそれ以外の合法手を同時に選べる局面を抽出します。各局面で**現在の**PROによるMCTSを実行して角の選択率を測ります。チェックポイントに保存された古い方策を現在のPROの選択として数えません。

一部の局面では、角を強制した分岐と、角の初回使用を見送る分岐を作り、その後を現行PRO対MID、現行PRO対現行PROで最後まで対局させます。同じ元局面・同じ候補側の色から始め、勝敗を比較します。現時点では現行PROと100回時点のPROは同じ重みです。追加学習後には、追加学習済みPROを`--pro`に指定すれば100回時点のPROを固定した比較相手にできますが、その場合は別途対戦相手のパスを指定できるようにプログラムを拡張する必要があります。

```powershell
cd python_ai
.\.venv\Scripts\python.exe -m time_inversi.corner_study `
  --pro runs\pro-finetune-pilot-20261023\pro100.pt `
  --mid runs\experiment01\latest.pt `
  --output runs\benchmarks\corner-study.json `
  --phases 0 1 2 3 --survey-per-phase 20 --rollout-per-phase 2 `
  --root-simulations 64 --rollout-simulations 16
```

結果の`corner_chosen`は、**合法な未使用角と別の手が同時にある局面**での選択回数です。`corner_mass`は探索訪問率の合計で、勝率ではありません。分岐対局の`corner_score`と`alternative_score`は候補側の得点（勝ち1、引き分け0.5、負け0）の合計です。初回角への着手では置いた駒が強制反転で直ちに消えますが、裏返しと時間方向の変更は残ります。

保存済みリプレイバッファは過去の学習で生成した局面なので、独立した検証用局面ではありません。また、少数の分岐対局や小さい探索回数から角の価値を断定しないでください。仮説の絞り込みに使い、採用する重み変更は別の乱数種と十分な対局数で黒白を揃えて検証します。

## 2026-10-23の予備結果

`runs/benchmarks/corner-survey-20261023.json`では、各段階100局面を64探索で調べました。未使用角を選んだのは、反転0回後23/100、1回後28/100、2回後29/100、3回後22/100です。この100局面だけでは、逆行中（1・3回後）だけ角を選びすぎる、または避けすぎるという単純な傾向は見えません。

`runs/benchmarks/corner-study-balanced-20261023.json`では、1回後・3回後の各40局面から黒白4局面ずつ、計8局面を分岐させました。続行は32探索/手です。1回後の角／見送りは、MID相手で5.0／5.0点、現行PRO相手でも4.0／4.0点でした。3回後はMID相手で3.5／5.0点、現行PRO相手で3.0／2.0点でした。各条件は8組だけであり、相手によって方向も変わるため、角の価値について結論は出せません。現行PRO相手という条件は、100回時点の同一重み同士の対局です。先に行った`corner-study-odd-phases-20261023.json`は黒白が偏っていたため、主な判断材料にしません。

どちらの結果も保存済みの学習用局面から抽出した探索的分析です。学習の重みを変える前に、独立に生成した局面・より多い組数・黒白別集計で再検証する必要があります。

## 反転済み角への入力感度

現行PROには反転回数ごとに独立した評価関数や固定の角点数はありません。`encoding.py`は使用済み角の位置を盤面チャネルに、順行・逆行を別のチャネルに入れ、配置履歴も入力します。共通のネットワークが着手確率と局面評価を計算します。したがって反転回数は使用済み角の数として読み取れますが、数値を単独で入力しているわけではありません。

感度確認として、100回目チェックポイントのリプレイバッファから各20局面を取り、**盤面、駒の配置方向、手番、現在の時間方向、両履歴を固定**し、狙う角以外の使用済み角だけ2つ増やしました。順行の0→2回では局面評価値の絶対差平均0.110、狙う角への着手確率の絶対差平均0.036、最上位手の変化6/20局面。逆行の1→3回ではそれぞれ0.038、0.018、3/20局面でした。順行0→4回（狙う角も使用済みにする）では着手確率の絶対差平均0.135、最上位手の変化9/20局面でした。よって出力は反転履歴の入力に実際に反応しています。

この操作で作った比較対象は必ずしも実際の対局で到達できる状態ではありません。数値は**入力感度の確認**であり、どの反転段階で角を適切に評価できているか、あるいは反転回数の情報だけを使っているかを証明しません。初回角と使用済み角では着手後のルール自体も異なります。
