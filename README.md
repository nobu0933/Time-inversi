# Time Inversi

`index.html` をブラウザで開くと遊べます。外部ライブラリやビルドは不要です。

画像1に合わせた6×6盤で、黒から始まる同一端末の2人対戦またはランダムCPUとの対戦です。マウスカーソルの代わりに手番のコマが追従します。合法マスの中心からマス幅の約80%以内に近づくと、最寄りの候補に着地点の影が現れ、クリックすると配置します。約100msで降下したあと一度小さく跳ね、計240msで接地してから挟んだコマが裏返ります。タッチでは明るいマスをタップして配置します。キーボードではTab・矢印キーで移動し、Enter・Spaceで配置できます。動きを減らす設定にも対応します。

時間反転は未使用の角への配置で発生します。手動のTIME INVERSIONボタンはありません。初期時刻まで戻っても自動では反転しません。詳しいルールは [時間反転ルール](docs/rules.md) を参照してください。

タイトルを押すとNew game?の確認が出ます。白CPUは初期オン、黒CPUは初期オフで、各CPUボタンで切り替えられます。CPUはランダムな合法手を置きます。パス時は中央にPASSの駒を800ms表示します。BGMボタンは初期オンですが音源はまだありません。終局後はBGMボタンの左に再生ボタンが現れます。UIはすべて英語で、逆行時は画面全体が青みを帯び、時間反転時に一度脈動します。

盤面上の懐中時計は、順行・逆行マスの個数を32分割の扇形で示します。パスだけでは扇形を増やさず、駒が消えた場合はその分だけ更新します。白い針は両方の扇の境界を指し、順行で時計回り、逆行で反時計回りに進みます。

描画はPenrosanneの `docs/ui-design.md` と `src/ui/BoardView.js`、P3NROSEの `docs/GAME_SPECIFICATION.md` と `src/ui/board.js`・`src/ui/editor.js` を参考に、単色の上面・下向きの側面・硬い影・100msの接地を円形コマに適用しています。参考プロジェクトには依存しません。

画面レイアウトは1080×1080の構図を基準に、縦横どちらの画面でも収まる倍率で全体を拡大・縮小します。盤面と時計・ボタン・結果表示の比率や位置関係は画面サイズによって変わりません。

ルールの検証: `node --test tests/*.test.cjs`

Python版ルールとAlphaZero方式の自己対戦学習は [学習環境の導入から実行までの手順](python_ai/README.md) を参照してください。Pythonが入ったPCで、この`Time Inversi`フォルダーだけから専用環境を作成できます。参考元の別フォルダーやNode.jsは学習には不要です。初回の依存ライブラリ導入にはインターネット接続が必要です。動作確認・本学習・停止／再開・評価の順にコマンドを掲載しています。

ローカルプレビュー: `node scripts/preview.cjs` を実行して `http://127.0.0.1:4173` を開きます。

## フォルダ構成

```text
Time Inversi/
├─ index.html                # ゲームの入口
├─ README.md                 # 起動方法・構成
├─ assets/icon/              # 順行・逆行の角時計、懐中時計、再生ボタンのSVG
├─ src/
│  ├─ game/rules.js          # リバーシのルール判定
│  ├─ game/replay.js         # 再生用の盤面スナップショット
│  └─ ui/game.js             # 画面描画・入力・アニメーション
├─ styles/style.css          # 配色・レイアウト・立体表現
├─ tests/                   # 基本ルール・時間反転のテスト
├─ scripts/preview.cjs       # 開発用プレビューサーバー
└─ docs/
   ├─ rules.md              # 時間反転のルール仕様
   ├─ references/           # 元の参考画像
   └─ screenshots/          # 実装画面の記録
```
