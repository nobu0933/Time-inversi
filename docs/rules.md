# 時間反転ルール

6×6盤・黒先手。初期4駒は時間方向を持たず、履歴の巻き戻しでは消えない。通常の8方向の挟み込みで配置・反転する。

## 時間方向と履歴

- 初期状態は順行。TIME INVERSIONで順行／逆行を切り替える。ボタン自体は手番を進めない。配置・反転・消滅の演出中と終局後は操作不可。
- 順行と逆行にそれぞれ未消化の手番履歴を持つ。配置はマス番号、パスは空の手番として記録する。
- 各手番は「配置と反転、またはパス → 現方向の履歴に記録 → 逆方向の履歴の最新1手を消化 → 強制方向切替 → 終了判定 → 相手へ交代」の順で処理する。
- 消化した手が配置なら、そのマスの駒を現在の色に関わらず消す。その駒が過去に裏返した他の駒は戻さない。パスなら何も消さず、さらに前の手を同時には消化しない。
- 逆行で順行履歴を使い切ったら、自動的に順行へ戻る。未消化のパスも時間上の1手として扱う。順行では逆行履歴がなくても続ける。
- 色が裏返っても駒の配置方向は変わらない。消えたマスへの再配置は新しい履歴として扱う。

## パスと終局

合法手がないときは約1.1秒の手番間隔の後に自動パスし、通常と同じ時間処理を行う。この間も時間反転ボタンを押せる。

消滅と強制方向切替を反映した盤面で、次のどれかを満たすと終局。石数の多い色が勝ち、同数は引き分け。

- 全36マスが埋まった。
- 黒または白が0個になった。
- 両者に合法手がなく、現在の時間方向と逆の駒が盤上にない。

## 表示

| 配置方向 | マスの縁 | マスの塗り |
| --- | --- | --- |
| 順行 | `#d86e46` | `#edbf7d` |
| 逆行 | `#336ac7` | `#9da1ff` |

初期駒と空きマスは通常色。消滅後は通常色へ戻す。消滅演出は小さな跳ね返りの後に上へ加速して消え、完了後に手番を交代する。
